# Anjneya Tech — Official Website

Mobile game studio website for Anjneya Tech, ready for GitHub Pages deployment.

## 📁 Files

| File | Purpose |
|------|---------|
| `index.html` | Main website homepage |
| `style.css` | All styles |
| `main.js` | Animations, game demo, interactions |
| `privacy.html` | Privacy policy page |
| `app-ads.txt` | Google AdMob ads.txt (IAB Tech Lab spec) |

## 🚀 Deploy to GitHub Pages

1. Create a new GitHub repository (e.g. `anjneyatech.github.io` or any name)
2. Upload all files to the repository root
3. Go to **Settings → Pages**
4. Under "Source", select **Deploy from a branch → main → / (root)**
5. Click **Save**
6. Your site will be live at `https://yourusername.github.io/repo-name`

## ✅ app-ads.txt Verification

After deployment, your app-ads.txt will be accessible at:
```
https://yourdomain.com/app-ads.txt
```

In Google AdMob:
1. Go to AdMob → Apps → Select your app
2. Enter your website domain (exactly as listed on Google Play)
3. Click **Verify** — AdMob will crawl your app-ads.txt
